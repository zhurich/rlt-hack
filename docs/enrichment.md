## Результат

Таблица `companies` (и `data/out/companies.csv` в формате исходных файлов): 508 184 компании.

**Известные поставщики (44 196 ИНН из истории):**

- название найдено у 27 537 — на них приходится 84,4% заявок;
  по юрлицам покрытие 89%, по 12-значным ИНН — 39% (остальные — физлица, не ИП);
- ОКВЭД известен у 25 434;
- в РНП — 524, с налоговой задолженностью больше 100 тыс. руб. — 2 153.

**Новые компании (463 988, которых нет в истории):**

- 164 276 юрлиц и 299 712 ИП;
- с ненулевой выручкой за 2025 г. — 122 754, с работниками — 127 763;
- в реестре МСП больше двух лет — 329 669; малые и средние (не микро) — 20 928;
- с лицензиями — 17 894;
- «крепкие» (выручка есть, в реестре больше двух лет, без существенной задолженности,

В пул подбора (`data/pool.pkl`) вошли 452 194 новые компании: с известным ОКВЭД и не из РНП.

## Роли

Правила (`enrich/companies.py`), для каждой компании записано обоснование и источник:

| Роль | Правило | Известные | Новые |
|---|---|---|---|
| производитель | основной ОКВЭД классов 01–32 либо в реестре МСП заявлена производимая продукция | 2 564 | 32 118 |
| дистрибьютор | основной ОКВЭД 46 (опт) или 45, кроме 45.2 (авторемонт — это услуги) | 7 973 | 45 799 |
| поставщик | всё остальное: розница (47), работы и услуги, ОКВЭД неизвестен | 33 659 | 386 071 |

Класс 33 (ремонт и монтаж оборудования) формально относится к разделу C, но это услуги —
к производителям не отнесён. У дистрибьютора отдельно помечается наличие производственных
ОКВЭД среди дополнительных.

## Подбор новых компаний под закупку

У новой компании нет истории, поэтому релевантность считается по реестровым данным
(`recsys/pool.py`):

1. **Связь «ОКВЭД → ОКПД2», выученная из истории.** Для каждого основного ОКВЭД известных
   поставщиков посчитано, какая доля их заявок приходится на каждую группу ОКПД2. Например,
   у оптовиков канцтоваров (46.49.33) высокая доля в бумаге (17.12). Новая компания с тем же
   ОКВЭД наследует эту связь. Всего 17 955 связей по 760 ОКВЭД.
2. **Прямое совпадение** основного или дополнительного ОКВЭД с группой ОКПД2 закупки
   (первые четыре цифры классификаторов устроены одинаково) — так находятся производители.
3. **Текстовая близость** предмета закупки к названию ОКВЭД, заявленной продукции и лицензиям.
4. Итог умножается на **достоверность** (от 0,05 до 1): есть выручка или работники, масштаб
   выручки, стаж в реестре больше двух лет, категория выше микро, лицензии; минус за
   налоговую задолженность больше 100 тыс. руб. Компании из РНП в пул не попадают.

Подбор новых компаний — около 50 мс, выдаётся отдельным списком рядом с основным.

### Проверка способа

Новых компаний в истории нет по определению, поэтому проверен сам способ: известные
поставщики ранжируются только по реестровым данным, как будто их истории закупок нет
(связь ОКВЭД→ОКПД2 учится на данных до 31.10.2025), и сравниваются с реальными участниками
лотов ноября–декабря 2025. 1 527 лотов, выбор из 25 434 компаний:

| | Recall@10 | Recall@50 | Recall@200 |
|---|---|---|---|
| Случайный выбор | 0,0004 | 0,0020 | 0,0079 |
| Только текст | 0,016 | 0,048 | 0,113 |
| Только совпадение основного ОКВЭД | 0,030 | 0,069 | 0,136 |
| Только связь ОКВЭД→ОКПД2 | 0,038 | 0,112 | 0,282 |
| **Принятый вариант** | **0,039** | **0,124** | **0,293** |

Реестровые данные находят реальных участников в 37–100 раз чаще случайного выбора.
Это намного слабее подбора по истории (Recall@10 0,660) — так и должно быть: ОКВЭД говорит
о том, чем компания может заниматься, а не о том, ходит ли она на госзакупки. Поэтому
новые компании показываются отдельным списком как расширение пула, а не подмешиваются
в основную выдачу.

Воспроизведение: `python scripts/validate_pool.py 2000`.

## Как пересобрать

```
python -m enrich.rmsp        # реестр МСП (архив data/ext/rsmp.zip, 2 ГБ), ~1 мин
python -m enrich.fns         # численность, доходы, задолженность, ~20 с
python -m enrich.rnp         # РНП из ЕИС, ~8 мин (запросы с паузой)
python -m enrich.companies   # справочник компаний, роли, выгрузка CSV
python -m recsys.pool        # пул новых компаний для подбора
```

Архивы ФНС лежат в `data/ext/` (в git не попадают), ссылки — в начале каждого модуля.
