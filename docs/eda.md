`python scripts/eda.py > docs/eda_output.txt`. Полные таблицы — в `eda_output.txt`.

## Две площадки — два разных набора данных

| | ЭМ | АИС ГЗ |
|---|---|---|
| Лотов | 271 806 | 332 646 |
| С участниками | 100% | 83,7% |
| Участников на лот | 2,69 в среднем | 1,0 (99,9% — один) |
| Один участник | 41,5% | 99,9% |
| Медиана цены | 55 000 | 167 172 |
| `is_smp = true` | 0 | 149 963 |
| `reqnum` | пусто всегда | заполнен у 231 513 |

**Главный вывод.** В АИС ГЗ известен только победитель (исполнитель контракта); проигравших
нет. Конкуренция видна только в ЭМ: 58,5% лотов с 2+ участниками, 4,1% — с 8 и более.
Поэтому сигнал «участвовал, но не победил» есть только для ЭМ, а метрику стоит считать
отдельно по площадкам.

- `is_smp` в ЭМ всегда `false` — признак несёт информацию только внутри АИС ГЗ.
- В ЭМ 6 970 лотов без победителя (~2,6%, ровно по месяцам — не обрезка по концу периода).
- Заказчики общие: 2 773 из 2 785 работают на обеих площадках.
- Поставщики пересекаются слабо: 25 375 только АИС ГЗ, 8 482 только ЭМ, 10 339 — обе.

## Качество полей

- **notices**: `start_price` пуст у 3, ≤ 0 у 24; `subject` пуст у 1. `customer_inn`/`kpp` пусты
  у 8 449 лотов (1,4%, обе площадки, весь период). `subject` = `procedure_name` в 98,6% —
  второе поле почти ничего не добавляет.
- **tru**: `product_name` пуст у 114, `okpd2_code` — у 238. Полных дублей строк — 164 879 групп
  (одинаковые позиции в лоте; для подбора схлопывать).
- **suppliers**: 31 дубль пары лот–поставщик (убрать `distinct`). `supplier_kpp` пуст у 191 361
  заявки — почти все это 12-значные ИНН (у ИП/физлиц КПП нет). Ещё 19 188 заявок с
  КПП `000000000` — тоже ИП. **Регион по КПП для ИП недоступен**; для них брать первые две
  цифры ИНН.
- **Битые ИНН**: 22 уникальных, 131 заявка из 1,01 млн. Из них `7817120232` (103 заявки) —
  формат верный, не сходится контрольная сумма; остальное — 9/13/15 знаков и `UJ65120100`.
  Объём ничтожный: не выбрасывать из подбора, но помечать и не обогащать.
- У 3 613 ИНН больше одного КПП (филиалы) — ключ контрагента только ИНН.
- Цены: длинный хвост до 40 млрд (мост, коллектор, перевозки). Сравнивать в логарифмах.

## ОКПД2

- 8 453 полных кода, 83 класса, 587 групп (4 знака), 3 079 категорий (6 знаков).
- Глубина разная: 94,8% позиций — полный 9-значный код, 2,5% — только 4 знака, 1,6% — 5,
  1,1% — 6. Иерархию строить по префиксам, а не ждать фиксированную длину.
- Длинный хвост: 1 447 кодов встречаются в одном лоте, 3 298 — меньше чем в пяти; медиана
  8 лотов на код. Для редких кодов нужен откат на уровень выше.
- На лот: медиана 1 позиция, среднее 4,9, p95 — 17, максимум 7 011. 17,1% лотов содержат
  несколько кодов, 8,8% — несколько классов.
- Топ классов по лотам: 32 (мединструменты и пр., 11,6%), 21 (лекарства, 8,0%),
  26 (электроника, 6,9%), 85 (образование, 6,5%), 20, 22, 17, 43.
- Названий позиций — 1,07 млн уникальных, `subject` — 371 тыс. уникальных, медиана 89
  символов: текст содержателен, TF-IDF имеет смысл. Регистр гуляет («Оказание» / «оказание»).

## Поставщики

- 44 196 уникальных ИНН: 20 592 юрлица, 23 597 двенадцатизначных.
- **Физлица-преподаватели.** 7 435 двенадцатизначных ИНН встречаются только в классе 85
  и только в АИС ГЗ (ГИА, преподавательские услуги по п.33 ч.1 ст.93). Это не рынок:
  в пул рекомендаций и в обогащение их не тянуть, в метрике учитывать отдельно.
- Активность: 16 004 с одной заявкой, 14 608 с 2–4, 8 309 с 5–19, 5 275 с 20+.
  Никогда не побеждали — 3 045.
- Концентрация: топ-100 — 28,2% заявок, топ-1000 — 64,8%, топ-10 000 — 92,6%.
  Лидер `7811756312` — 21 610 заявок у 2 526 заказчиков в 39 классах: универсальные
  «охотники» из ЭМ забьют выдачу по голой популярности, нужна нормировка на специализацию.
- Специализация (5+ заявок): медиана 3 класса ОКПД2; 42% работают в ≤ 2 классах,
  11,6% — в 10 и более.
- История с заказчиком сильна: 64,2% заявок приходятся на пары заказчик–поставщик,
  встречавшиеся 2+ раза.

## Что это значит для следующих шагов

- **Потолок базового подбора высокий.** В последних двух месяцах (после 2025-10-31:
  64 881 лот, 119 598 заявок) 96,1% заявок подали поставщики, уже встречавшиеся в истории.
  Recall ограничен ранжированием, а не пулом.
- **Метрика (шаг 3):** разбиение по дате с отсечкой 2025-10-31; считать раздельно ЭМ
  (все участники и победитель) и АИС ГЗ (только победитель); физлиц класса 85 — отдельной
  строкой, иначе они испортят цифру.
- **Факторы (шаг 2):** ОКПД2 по префиксам с откатом; текст названий; пара
  заказчик–поставщик; лог-цена; регион поставщика (КПП или ИНН); СМП — только для АИС ГЗ;
  штраф за неспециализированность.
- **Обогащение (шаг 4)** важнее, чем казалось: внутри данных новых поставщиков почти нет,
  расширение пула возможно только из внешних реестров. База для сопоставления — 20,6 тыс.
  юрлиц и ~16 тыс. ИП.
